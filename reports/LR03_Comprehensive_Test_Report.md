# ОТЧЁТ ПО ЛАБОРАТОРНОЙ РАБОТЕ №3

## Тема работы
Тестирование и отладка программного обеспечения на примере проекта DCIM Sorter.

---

# 1. Цель работы

Целью лабораторной работы является проведение комплексного тестирования разработанного программного продукта, выявление и устранение ошибок, а также подтверждение стабильности и корректности работы программы.

В качестве объекта тестирования используется приложение DCIM Sorter — программа для автоматической сортировки фотографий и видеофайлов по дате создания.

---

# 2. Краткое описание программы

DCIM Sorter представляет собой настольное приложение с графическим интерфейсом, разработанное на языке Python с использованием библиотеки Tkinter.

Основные возможности программы:

- сортировка фотографий и видео по дате;
- поддержка режимов копирования и перемещения;
- построение иерархической структуры папок;
- поддержка плоского режима сортировки;
- автоматическое разрешение конфликтов имён;
- обработка неподдерживаемых файлов;
- отображение прогресса выполнения;
- безопасное прерывание сортировки;
- работа с вложенными каталогами.

Поддерживаемые форматы:

- изображения: JPG, JPEG, PNG, WEBP, HEIC, BMP, TIFF, DNG, RAW, ARW, CR2, NEF;
- видео: MP4, MOV, AVI, MKV, WMV, FLV, WEBM, 3GP, M4V.

# 6. Обнаруженные проблемы и исправления
