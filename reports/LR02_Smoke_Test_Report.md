# Отчёт о результатах смоук-тестирования

## 1. Цель тестирования
Проверка работоспособности программы после разработки, а также корректности запуска и выполнения основной функции сортировки файлов.

## 2. Условия проведения тестирования
- Операционная система: Windows 10 Pro
- Способ запуска: через файл Run.vbs
- Среда выполнения: локальный персональный компьютер

## 3. Тестовые данные
В качестве тестовых данных использовалась папка, содержащая 3 файла:
- Два файла с одинаковой датой создания, но различным временем
- Один файл с отличающейся датой (другой год)

## 4. Ход тестирования
1. Запущена программа с использованием файла Run.vbs
2. Выбрана входная папка с тестовыми файлами
3. Указана папка для сохранения отсортированных файлов
4. Выполнен запуск процесса сортировки

## 5. Результаты тестирования
В результате выполнения программы:
- Все файлы были успешно обработаны
- Файлы были корректно отсортированы по дате создания
- Для файлов с одинаковой датой учитывалось различие во времени
- Ошибки во время выполнения программы не возникли

## 6. Вывод
Программа успешно прошла смоук-тестирование. Основная функциональность реализована корректно, программа готова к проведению комплексного тестирования.
